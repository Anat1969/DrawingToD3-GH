# תוכנית בדיקות: ציור לתלת-ממד

## בדיקות המציג (קובץ model-viewer.html)
- [ ] נטען מודל לדוגמה בפתיחה, והסיבוב האוטומטי עובד.
- [ ] גרירה מסובבת את המודל, וגלגלת משנה את הזום.
- [ ] כפתור "תצוגת רשת" מחליף בין מצב רגיל לרשת.
- [ ] טעינת קובץ STL מציגה את המודל, והמונה מציג מספר משולשים.
- [ ] טעינת קובץ OBJ עובדת.
- [ ] טעינת קובץ GLB עובדת.
- [ ] קובץ מסוג לא נתמך (למשל PDF) מציג הודעה ברורה.
- [ ] המציג נראה תקין במסך של טלפון (רוחב כ-400px) בלי גלילה אופקית.

## בדיקות ההמרה (אחרי חיבור השרת)
- [ ] העלאת ציור PNG עובדת.
- [ ] העלאת ציור JPG ו-WEBP עובדת.
- [ ] קובץ גדול מ-20MB נדחה עם הודעה.
- [ ] בזמן ההמרה מוצגים אחוזים, ולא מסך קפוא.
- [ ] כשלון במחולל מציג הודעה ואפשרות לנסות שוב.
- [ ] המודל שנוצר נראה מכל צד (לבדוק שהגוף סגור, בלי "גב ריק").
- [ ] הקו השחור מופיע כנפח, וכתמי הצבע כעשן שקוף.
- [ ] הורדת GLB עובדת, והקובץ נפתח בתוכנת תלת-ממד אחרת.

## בדיקות אבטחה
- [ ] מפתח ה-API לא מופיע בקוד החזית או בתשובות הרשת.
- [ ] קבצי הקלט והפלט הזמניים נמחקים.

## בדיקות הדפסה (לשלב העתידי)
- [ ] קובץ STL שנוצר נטען בתוכנת הדפסה ללא שגיאות.
