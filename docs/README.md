# ציור לתלת-ממד

אפליקציה שמקבלת ציור דו-ממדי ומייצרת ממנו מודל תלת-ממדי שלם, שאפשר לצפות בו מכל צד, להוריד ולהדפיס.

## מצב נוכחי (27.10.2026)
- מציג תלת-ממד מוכן: טעינת STL, OBJ, GLB ו-GLTF, סיבוב 360 מעלות, תצוגת רשת ומודל לדוגמה.
- המרה מציור למודל: טרם מחוברת. דורשת מחולל מודלים (Hunyuan3D מקומי או שירות חיצוני).
- פורמט 3MF: טרם נתמך.

## מסמכים בתיקייה הזו
- spec.md: אפיון המוצר, המשתמשת, הזרימה המרכזית והמוצר המינימלי.
- technical.md: ארכיטקטורה, חיבור למחולל מודלים, אבטחה ומבנה הקבצים.
- setup-hardware.md: דרישות חומרה, התקנת מנהל התקן NVIDIA והפעלת Hunyuan3D.
- test-plan.md: רשימת בדיקות לכל שלב.
- claude-code-prompt.md: פרומפט הבנייה ל-Claude Code, כולל הפקודה להתחלה.

## הפעלה מהירה
פתיחת מציג התלת-ממד: לפתוח את קובץ model-viewer.html בדפדפן מחובר לאינטרנט (הקובץ נמצא בתיקיית הפרויקט של Claude).
