# הכנת המחשב והתקנת Hunyuan3D

## מצב המחשב שנבדק (27.10.2026)
- מעבד גרפי: Intel משולב בלבד (Intel Graphics, דרייבר 32.0.101.7076).
- זיכרון RAM: 16GB.
- אין כרטיס NVIDIA מזוהה, לכן אין הרצה מקומית של Hunyuan3D במצב הנוכחי.

## מה צריך כדי להריץ את Hunyuan3D מקומית
1. כרטיס NVIDIA עם זיכרון גרפי מספיק. לאמת את הדרישה המדויקת בעמוד הפרויקט הרשמי של Hunyuan3D, כי הדרישה משתנה לפי הגרסה (שלב הצורה מול שלב הטקסטורה).
2. מנהל התקן NVIDIA עדכני.
3. Python 3.10 עד 3.12 (לבדוק בתיעוד הפרויקט איזו גרסה נתמכת).
4. Git ו-CUDA בגרסה שתואמת למנהל ההתקן וללספריות של הפרויקט.
5. מומלץ 32GB RAM. עם 16GB ההרצה איטית ויכולה להיכשל בשלב הטקסטורה.

## רכישת כרטיס: המלצה לבדיקה
- כרטיס מינימלי: NVIDIA RTX 3060 עם 12GB.
- נוח יותר: NVIDIA RTX 4060 Ti עם 16GB.
- לפני רכישה לבדוק: האם המחשב נייד או שולחני, אם יש מקום פיזי וחיבור PCIe x16, ואם ספק הכוח מספיק (בדרך כלל 550W ומעלה לכרטיס כזה, לאמת לפי הדגם).
- מחשב נייד ללא חיבור חיצוני לא יתאים לכרטיס שולחני. אפשר לבדוק eGPU, אבל זה יקר יותר ואיטי יותר.
- מחירים משתנים, לכן לבדוק באתר החנות לפני הקנייה.

## התקנת Hunyuan3D (שלבים כלליים)
1. להוריד את הקוד מהמאגר הרשמי של הפרויקט בגיטהאב.
2. ליצור סביבת Python נפרדת (venv או conda) ולהתקין את הדרישות.
3. להוריד את משקלות המודל (weights) בהתאם להוראות.
4. להריץ את דוגמת הפקודה מהתיעוד, עם תמונה לבדיקה, ולוודא שנוצר קובץ GLB.
5. רק אחרי ההצלחה לחבר את השרת של האפליקציה למתאם.

## בדיקה מהירה לפני ההתקנה המלאה
- לפתוח PowerShell ולהריץ: nvidia-smi. אם הפקודה לא מזוהה, אין מנהל התקן NVIDIA מותקן.
- ב-Task Manager, בלשונית Performance, לבדוק את סעיף GPU.
