# ציור לתלת-ממד

מעלים ציור, והאפליקציה מחזירה מודל תלת-ממדי שאפשר לסובב ולהוריד כקובץ GLB.

## מבנה
- `index.html` ו-`src/`: הממשק (Vite, Three.js). עברית, RTL, ללא אייקונים. שפת העיצוב: `.claude/skills/darkroom-design-language/SKILL.md`.
- `api/convert.js`: מקבל ציור, בודק את סוג הקובץ לפי הבייטים, ושולח ל-Meshy. המפתח נשאר בשרת.
- `api/status.js`: מחזיר מצב המרה, ואחרי הצלחה קישורי GLB, STL ו-3MF.
- `tests/`: בדיקות יחידה לשרת ובדיקת Playwright מקצה לקצה.

## הפעלה
1. ליצור תוכנית בתשלום ב-Meshy ולהפיק מפתח API בעמוד https://www.meshy.ai/developers/keys. תוכנית חינמית לא מאפשרת קריאות API.
2. להעתיק את `.env.example` ל-`.env.local` (ב-Vercel להגדיר את המשתנים בלוח הבקרה) ולמלא:
   - `MESHY_API_KEY`: המפתח. חובה.
   - `MESHY_MODEL`: אופציונלי. ברירת מחדל `latest`.
3. להעלות את התיקייה ל-Vercel (או להריץ מקומית עם `vercel dev`). Vercel מזהה Vite ובונה ל-`dist`.

## מגבלות ידועות
- הגודל לאחר הקטנה בדפדפן עד כ-4MB, בגלל מגבלת הבקשה של פונקציות Vercel. ציורים גדולים מוקטנים אוטומטית.
- ההיסטוריה נשמרת בדפדפן בלבד (localStorage), ולא נראית ממכשיר אחר.
- אין הגבלת קצב לכל משתמש. לפני פרסום ציבורי יש להוסיף הגבלה.
- Meshy גובה קרדיטים לכל המרה. בדקי את העלות בתוכנית שבחרת.

## לאמת לפני פרסום
- שדות התשובה של Meshy נבדקו מול התיעוד (28.10.2026), אבל לא מול המרה אמיתית. ההמרה הראשונה עם מפתח היא הבדיקה.
- טעינת GLB מקישור Meshy ישירות במציג תלויה ב-CORS של השרת שלהם. אם נחסם, מוצגת הודעה והקבצים זמינים להורדה.

## שלב הבא: ציור תלת-ממדי
המטרה היא שבעתיד המשתמש יוכל לצייר ישירות במרחב. זה מוצר נפרד שדורש מנוע ציור תלת-ממדי ושמירה של קווים במרחב. הבסיס בפרויקט הוא מציג וה-API. הציור במרחב ייבנה כשיהיה מוגדר מה הוא צריך לייצא.
